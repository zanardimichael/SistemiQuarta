La **linea console** è l'accesso locale allo switch tramite cavo. Anche se richiede accesso fisico, va protetta con una password, altrimenti chiunque vi si colleghi entra nello switch.

<Callout icon="information" title="Scenario di esempio">

| Parametro        | Valore       |
|------------------|--------------|
| Hostname         | SW1          |
| Password console | Console!2024 |

</Callout>

## Prerequisiti

- Hostname e password di enable configurati.
- Accesso alla modalità di configurazione globale.

## Procedura

<Steps>

### Entrare nella configurazione della linea console

```cisco
SW1> enable
SW1# configure terminal
SW1(config)# line console 0
SW1(config-line)#
```

### Impostare la password e abilitare il login

```cisco
SW1(config-line)# password Console!2024
SW1(config-line)# login
```

<Aside type="caution">
Senza il comando `login` la password viene ignorata.
</Aside>

### Migliorare l'uso della console (facoltativo)

```cisco
SW1(config-line)# logging synchronous
SW1(config-line)# exec-timeout 5 0
SW1(config-line)# exit
```

- `logging synchronous` evita che i messaggi di sistema interrompano la riga che stai scrivendo.
- `exec-timeout 5 0` chiude la sessione dopo 5 minuti di inattività.

### Alternativa: login con utente locale

```cisco
SW1(config)# username admin secret Admin!2024
SW1(config)# line console 0
SW1(config-line)# login local
SW1(config-line)# end
```

Con `login local` la console richiede utente e password, che non sono più quelli impostati con `password`.

### Verificare

```cisco
SW1# show running-config | section line con
SW1# exit
```

Il banner MOTD (vedi la prima pagina) appare, poi viene richiesta la password.

```cisco
User Access Verification

Password:
SW1>
```

### Salvare la configurazione

```cisco
SW1# copy running-config startup-config
```

</Steps>

## Comandi utili

| Comando                    | Funzione                                   |
|----------------------------|--------------------------------------------|
| `line console 0`           | Entra nella configurazione della console   |
| `password PASSWORD`        | Imposta la password di linea               |
| `login`                    | Richiede la password di linea              |
| `login local`              | Richiede utente e password locali          |
| `logging synchronous`      | Evita interruzioni dei messaggi di sistema |
| `exec-timeout MIN SEC`     | Timeout per inattività                     |

## Esercizio

1. Configura una password per la console e abilita `login`.
2. Imposta `logging synchronous` ed `exec-timeout 10 0`.
3. Esci, rientra e verifica che venga richiesta la password dopo il banner.
4. Salva la configurazione.
