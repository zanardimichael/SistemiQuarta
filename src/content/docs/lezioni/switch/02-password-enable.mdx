La password di **enable** protegge l'accesso alla modalità privilegiata (`Switch#`), da cui si può modificare la configurazione. Senza password chiunque si colleghi alla console può farlo.

<Callout icon="information" title="Scenario di esempio">

| Parametro       | Valore       |
|-----------------|--------------|
| Hostname        | SW1          |
| Password enable | Cisco!2024   |

</Callout>

## Prerequisiti

- Hostname configurato (vedi la pagina precedente).
- Accesso alla modalità di configurazione globale.

## enable secret o enable password

| Comando           | Memorizzazione                   | Uso                |
|-------------------|----------------------------------|--------------------|
| `enable password` | Testo in chiaro (o cifratura debole tipo 7) | Da evitare |
| `enable secret`   | Hash (MD5, tipo 5; o tipi più robusti) | **Consigliato** |

Se sono presenti entrambi, IOS usa `enable secret`.

## Procedura

<Steps>

### Entrare in configurazione globale

```cisco
SW1> enable
SW1# configure terminal
SW1(config)#
```

### Impostare la password con enable secret

```cisco
SW1(config)# enable secret Cisco!2024
```

### Cifrare le altre password in chiaro (facoltativo)

```cisco
SW1(config)# service password-encryption
```

Cifra con tipo 7 le password che non sono già hashate (console, VTY). È un'offuscazione reversibile, non una vera protezione.

### Verificare

```cisco
SW1(config)# end
SW1# show running-config | include enable
enable secret 5 $1$mERr$...
```

La password non è visibile in chiaro.

Per testare:

```cisco
SW1# disable
SW1> enable
Password:
SW1#
```

### Salvare la configurazione

```cisco
SW1# copy running-config startup-config
```

</Steps>

## Comandi utili

| Comando                         | Funzione                                |
|---------------------------------|-----------------------------------------|
| `enable secret PASSWORD`        | Imposta la password di enable (hash)    |
| `no enable secret`              | Rimuove la password                     |
| `service password-encryption`   | Cifra le password in chiaro             |
| `disable`                       | Torna alla modalità user EXEC           |

<Aside type="caution" title="Attenzione">
Non usare `enable password`: la password è leggibile in `running-config` o facilmente decifrabile. Se la password viene dimenticata serve la procedura di recupero password con accesso fisico.
</Aside>

## Esercizio

1. Imposta `enable secret` con una password a tua scelta.
2. Verifica con `show running-config` che non sia in chiaro.
3. Esci con `disable` e prova a rientrare con `enable`.
4. Salva la configurazione.
